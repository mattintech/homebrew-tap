# Mattintech Tap

## How do I install these formulae?

`brew install mattintech/tap/<formula>`

Or `brew tap mattintech/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mattintech/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
